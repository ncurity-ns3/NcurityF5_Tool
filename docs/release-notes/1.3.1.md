# 1.3.1 — OWASP 전체 목록, VPE 매크로

GitHub Releases에서 Windows 설치 파일과 portable ZIP을 받아 실행합니다. Python 설치는 필요 없습니다.

- OWASP Top 10 테스트에 2017년과 2021년 curl을 넣었습니다. 2025년은 아직 목록이 없습니다.
- 2017년에서 curl이 없는 오탐 항목과 대용량 페이로드 항목은 빠졌습니다.
- VPE Viewer에서 Access Policy와 매크로를 카드로 나눴습니다. 매크로는 처음에 모두 접혀 있고, 막대의 펼치기/접기로 엽니다. 긴 이름은 박스 안에서 줄바꿈됩니다.
- OWASP Top 10은 항목별로 공격, 차단, 통과, 실패 건수만 보여 줍니다. 응답 전문은 Report에서 봅니다.
- 요청 작성에서 Method, URI, 헤더, 쿠키, 파라미터, 로그인을 직접 넣어 보낼 수 있습니다.

설치 파일: `NcurityF5Tool-1.3.1.msi`  
실행 파일: 설치 후 `NcurityF5Tool.exe`  
Portable ZIP: `NcurityF5Tool-1.3.1-win64-portable.zip`
