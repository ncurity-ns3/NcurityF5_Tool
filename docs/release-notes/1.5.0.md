# 1.5.0 — 점검, N-Health, 트러블슈팅 수집

GitHub Releases에서 Windows 설치 파일을 받아 실행합니다. Python 설치는 필요 없습니다.

## VPE Viewer

- 오른쪽 Description과 옵션 값을 읽기 쉽게 표시합니다.
- 마우스 가운데 버튼으로 화면을 스크롤합니다.

## VPE Macro Copy

- Logon Page, Message Box 같은 Web Customizing은 필요할 때만 반영합니다.
- 매크로는 한 번에 하나를 복사합니다.

## OWASP Top 10

- 차단 페이지 메시지를 등록해 차단 여부를 확인합니다.

## Home

- 왼쪽 메뉴 전체를 접고 펼 수 있습니다.
- 큰 항목은 Home, Device Check, APM, WAF, N-Health, Initial Setup, Reports, Settings입니다.
- 앱을 열면 Home이 열려 있습니다. 다른 큰 항목은 접혀 있고, 연 항목 안의 화면이 선택되어 보입니다.

## OS 업그레이드 간 점검

- Device Group Name이 표시됩니다.

## 정기 점검

- QKView로 정기 점검을 합니다.
- 중요 System 로그를 확인합니다.

## Host Content

- UCS를 올리면 Host Content 파일을 추출합니다.

## SSL 인증서

- 사용 중인 SSL Profile 인증서의 만료 기한을 확인합니다.

## N-Health

기능 이름은 iHealth에서 가져왔습니다.

### Release Notes Checker

- Bug ID를 저장해 두고, 새 버전이나 엔지니어링 핫픽스에서 Fixed인지 확인합니다.
- 이슈 정리는 Basic과 Advanced가 있습니다.
  - Basic은 버전과 선택한 모듈의 이슈를 봅니다.
  - Advanced는 QKView 또는 UCS 설정에 해당하는 이슈를 봅니다.

### CVE Vulnerability Checker

- 버전을 고르고 CVE를 검색합니다.
- 해당 여부는 K 문서를 기준으로 표시합니다.

## 트러블슈팅 자료 수집

- Qkview와 로그 압축을 장비에서 만들어 PC로 받습니다.
- Core 파일이 있으면 경로를 보여 줍니다. 파일은 장비에 그대로 둡니다.
- UCS를 저장하고, f5mku -K 결과를 같은 폴더에 저장합니다.

## 장비 연결

- 한 탭에서 Test Connection에 성공하면, 다른 탭의 빈 연결 칸에 같은 장비 정보가 채워집니다.

설치 파일: `NcurityF5Tool-1.5.0.msi`  
실행 파일: 설치 후 `NcurityF5Tool.exe`  
Portable ZIP: `NcurityF5Tool-1.5.0-win64-portable.zip`
