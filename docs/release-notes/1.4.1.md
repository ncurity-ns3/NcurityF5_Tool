# 1.4.1 — N-Health, SSL, Host Content

GitHub Releases에서 Windows 설치 파일을 받아 실행합니다. Python 설치는 필요 없습니다.

- N-Health 메뉴를 추가했습니다. Release Notes Checker에서 버그 목록을 저장하고, 선택한 버전의 Release Note를 검색합니다.
- 버전은 17.5.1.11 (Build 12.0)처럼 실제 릴리스 번호와 Build를 보여 줍니다.
- Basic은 체크한 모듈의 Release Note, 버그, 취약점을 정리합니다. Advanced는 UCS 또는 QKView 설정에 있는 기능의 이슈만 정리합니다.
- Severity는 고른 등급과 그보다 높은 등급을 표시합니다. 릴리스 노트에 등급이 없으면 공개 버그 트래커에서 받아 저장합니다.
- 레포트에서 키워드, 이번 검색의 모듈, Severity, Fixed/Known으로 거릅니다. 모듈 구간은 색으로 구분됩니다.
- CVE Vulnerability Checker, Config Viewer, 이슈 분석자료 수집, Log Search는 메뉴만 있습니다.
- SSL 인증서 확인과 Host Content 추출을 넣었습니다.
- 정기 점검에서 QKView로 상태와 성능 그래프를 볼 수 있습니다.

설치 파일: `NcurityF5Tool-1.4.1.msi`  
실행 파일: 설치 후 `NcurityF5Tool.exe`  
Portable ZIP: `NcurityF5Tool-1.4.1-win64-portable.zip`
