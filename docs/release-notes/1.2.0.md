# 1.2.0 — VPE Viewer, 납품확인서

GitHub Releases에서 Windows 설치 파일과 portable ZIP을 받아 실행합니다. Python 설치는 필요 없습니다.

- APM 메뉴에 VPE Viewer를 넣었습니다. qkview, UCS, bigip.conf의 Access Policy 흐름을 봅니다.
- VPE Macro 메뉴 이름은 VPE Macro Copy입니다.
- Device Check에 납품확인서 작성을 넣었습니다. Word 파일은 `%LOCALAPPDATA%\f5tool\output`에 저장됩니다.
- 왼쪽 메뉴를 Home, Device Check, APM, Initial Setup, Reports, Settings로 나눴습니다. Devices 메뉴는 뺐습니다.

설치 파일: `NcurityF5Tool-1.2.0.msi`  
실행 파일: 설치 후 `NcurityF5Tool.exe`  
Portable ZIP: `NcurityF5Tool-1.2.0-win64-portable.zip`
