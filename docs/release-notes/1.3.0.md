# 1.3.0 — WAF, OWASP Top 10 PoC

GitHub Releases에서 Windows 설치 파일과 portable ZIP을 받아 실행합니다. Python 설치는 필요 없습니다.

- WAF 메뉴에 OWASP Top 10 테스트를 넣었습니다. PoC 전용입니다.
- 연도는 2017, 2021, 2025 중에서 고릅니다. 1.3.0에서 목록이 있는 연도는 2021년입니다.
- IP, Host, HTTP/HTTPS를 입력한 뒤 전송하면 그 대상으로 curl을 보냅니다. 기타를 고르면 포트와 프로토콜을 직접 지정합니다.
- 2021년 항목은 A1 Broken Access Control 01–03, A3 Injection 01–07 입니다.

설치 파일: `NcurityF5Tool-1.3.0.msi`  
실행 파일: 설치 후 `NcurityF5Tool.exe`  
Portable ZIP: `NcurityF5Tool-1.3.0-win64-portable.zip`
