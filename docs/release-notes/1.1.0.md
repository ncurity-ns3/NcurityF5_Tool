# 1.1.0 — APM Macro

VPE Macro 화면에서 Access Profile의 Macro를 저장하고, 같은 장비나 다른 장비의 Access Profile에 새 Macro로 불러옵니다.

- Macro 안의 Logon Page, AD Auth, AD Query, 종료, 규칙을 저장합니다.
- AAA 서버, Customization Group, 리소스, SMTP 이름은 저장하지 않습니다. Load하면 해당 항목은 비어 있습니다.
- Logon Page, Message Box, Decision Box는 새 Customization Group(`source modern`)을 만듭니다. `user-logon.css`, `user-logon.js` 같은 기본 파일은 장비가 같이 만듭니다.
- 같은 이름이 있으면 다음 번호(`Auth_AD`, `Auth_AD_1`, …)로 만듭니다. 원본 Macro는 바꾸지 않습니다.
- 생성은 tmsh 트랜잭션 한 번입니다. 실패하면 이번에 만든 Macro만 지웁니다.
- 다른 장비의 Access Profile 목록은 별도 curl 프로세스가 조회합니다.
- 만든 Macro는 대상 Access Profile의 Access Policy Macro 목록에 연결됩니다. 정책 본문 흐름을 바꾸지는 않습니다.

설치 파일: `dist\installer\NcurityF5Tool-Setup-1.1.0.exe`  
Portable ZIP: `dist\release\NcurityF5Tool-1.1.0-win64-portable.zip`
